Each dot is one replicate from a CI job; the bar marks each browser's median (per day in the By day view, where days run left to right by the date each job reported). The By hour view keeps only the UTC hours, by job start time, in which both browsers ran that protocol, so the comparison and medians use runs that saw the same network conditions. The Time of day view places each replicate at its job's UTC start time, folding all days onto one 24-hour axis, to show daily trends (the test runs within about 2 minutes of job start; spread within a job is jitter). Connection times and latency are in ms (lower is better); downloads and uploads are throughput in Mbps (higher is better), from each transfer's size and duration. The three charts for a metric share an axis. Above each chart, Firefox is compared with Chrome using the median, and each browser's coefficient of variance (standard deviation / mean) shows how noisy it is.
